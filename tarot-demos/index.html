Twelve ways your booking site could look.

Every one is a complete five-page website — home, readings, about, booking and contact — running the same practitioner, the same five readings and the same prices. The only thing that changes is the design.

How to use this: open each one, click through the pages, then say which direction feels like you. Nothing here is a mock-up image — every page is real and clickable, including the booking flow.
Headings are now capped for readability across all twelve, after the note that oversized display type was hard to read. Hierarchy comes from colour, spacing and ornament instead of raw size.
